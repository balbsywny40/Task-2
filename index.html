إزاي المواقع بتتفاعل مع ضغطات المستخدم: JavaScript

اسم الطالب: زياد عبده طه

الرقم الجامعي: 2501125

المقدمة

أصبحت المواقع الإلكترونية جزءاً مهمّاً من حياتنا اليومية، فنحن نستخدمها في التعلم والتسوق ومشاهدة الفيديوهات والتواصل مع الآخرين. والموقع الجيد لا يكتفي بعرض المعلومات فقط، ولكنه يسمح للمستخدم بالتفاعل مع العناصر الموجودة أمامه، مثل الضغط على الأزرار أو كتابة البيانات أو فتح القوائم.

هنا يأتي دور لغة JavaScript، وهي لغة برمجة تُستخدم لإضافة الحركة والتفاعل إلى صفحات الويب. فعندما نضغط على زر في موقع فتظهر رسالة، أو نختار منتجاً فيتغير السعر، أو نكتب كلمة فيظهر اقتراح مناسب، تكون هي المسؤولة عن تنفيذ هذا السلوك.

عرض الموضوع

فكرة البحث

يتناول هذا البحث كيفية استخدام JavaScript للتعامل مع ضغطات المستخدم، وكيف تتعرف الصفحة على الحدث ثم تنفذ الأمر المطلوب. كما يعرض أمثلة بسيطة توضح الفكرة، وأهمية هذه اللغة في جعل استخدام المواقع أسهل وأكثر وضوحاً.

ما المقصود بتفاعل المستخدم؟

تفاعل المستخدم هو أي تصرف يقوم به الشخص داخل الموقع ويؤدي إلى استجابة من الصفحة. ومن أمثلته الضغط على زر، أو إدخال نص في مربع بحث، أو تحديد اختيار من قائمة، أو إرسال نموذج يحتوي على بيانات. والاستجابة قد تكون ظهور رسالة، أو تغيير جزء من الصفحة، أو الانتقال إلى خطوة أخرى.

ما هي JavaScript؟

هي إحدى لغات البرمجة المستخدمة في تطوير مواقع الويب. تعمل غالباً مع HTML و CSS؛ حيث يحدد HTML محتوى الصفحة وعناصرها، بينما تضيف CSS تنسيق شكلها وألوانها، وتهتم JavaScript بالسلوك والتفاعل.

على سبيل المثال، يمكن أن تحتوي الصفحة على زر مكتوب عليه «اعرف المزيد»، يظهر الزر باستخدام HTML، ويمكن تنسيقه باستخدام CSS، ثم تُستخدم JavaScript لتحديد ما يحدث عندما يضغط المستخدم عليه.

صورة توضيحية لبرمجة JavaScript

كيف تعرف الصفحة أن المستخدم ضغط على زر؟

تستطيع JavaScript الاستماع إلى الأحداث التي تحدث داخل الصفحة. والحدث هو تصرف أو تغيير يمكن للبرنامج ملاحظته، مثل النقر بالماوس، أو الضغط على أحد مفاتيح لوحة المفاتيح، أو الكتابة داخل خانة، أو إرسال نموذج.

من أشهر الأحداث حدث click، وهو الذي يحدث عند الضغط على عنصر. ويمكن للمبرمج ربط هذا الحدث بزر معين، ثم كتابة تعليمات تُنفذ عند وقوعه. بهذه الطريقة لا تحتاج الصفحة إلى إعادة تحميل كاملة كل مرة يريد فيها المستخدم تنفيذ أمر بسيط.

جدول مقارنة لأشهر الأحداث (Events) في JavaScript

اسم الحدث (Event) وصف الحدث حالة الاستخدام الشائعة
click يحدث عند النقر بالماوس على عنصر معين الضغط على الأزرار لإرسال البيانات أو إظهار القوائم
input / change يحدث عند تغيير النص أو اختيار قيمة داخل مربع إدخال متابعة الكتابة داخل حقول البحث أو الاستمارات
submit يحدث عند إرسال النموذج (Form) التحقق من صحة البيانات وإرسال التسجيل

مثال عملي بسيط

يوضح المثال التالي زراً يغير النص الظاهر على الصفحة عند الضغط عليه. يتكون المثال من عنصر HTML لعرض النص، وزر، وكود JavaScript يستجيب لحدث النقر.

الكود:

HTML:

<p id="message">أهلاً بك في الموقع</p>
<button id="myButton">اضغط هنا</button>

JavaScript:

document.getElementById('myButton').addEventListener('click', function() {
    document.getElementById('message').textContent = 'تم الضغط على الزر بنجاح!';
});

أهمية JavaScript في تجربة المستخدم

تساعد JavaScript على جعل المواقع أكثر سهولة وفاعلية؛ فهي تتيح تنفيذ كثير من المهام دون الحاجة إلى الانتقال إلى صفحة جديدة في كل مرة. ومن أمثلة ذلك التحقق من البيانات قبل إرسالها، وتحديث نتائج البحث، وإظهار رسائل التأكيد، وفتح القوائم المنسدلة.
